## Langkah 2 — Helper cari produk by slug

Semua produk tersebar di beberapa array (`featuredProducts`, `newArrivals`, `japaneseKnives`, `monthlyPick`). Buat satu fungsi lookup. File baru `src/entities/product/lib/get-product.ts`:

```ts
// src/entities/product/lib/get-product.ts
import {
  featuredProducts,
  japaneseKnives,
  monthlyPick,
  newArrivals,
} from "@/entities/product/model/product.data";
import { type Product } from "@/entities/product/model/product.types";

/** Gabungan seluruh katalog. Nanti diganti query CMS/API by slug. */
export const allProducts: Product[] = [
  ...japaneseKnives,
  ...featuredProducts,
  ...newArrivals,
  monthlyPick,
];

export function getProductBySlug(slug: string): Product | undefined {
  return allProducts.find((product) => product.slug === slug);
}

/** Produk lain di kategori sama (untuk "You may also like"). */
export function getRelatedProducts(product: Product, limit = 4): Product[] {
  const seen = new Set<string>();
  return allProducts
    .filter((p) => p.category === product.category && p.slug !== product.slug)
    .filter((p) => (seen.has(p.slug) ? false : seen.add(p.slug)))
    .slice(0, limit);
}
```

> Catatan: `japaneseKnives` dan `featuredProducts` punya beberapa slug yang sama (mis. `aoi-gyuto-210`). `find` mengambil yang pertama — itulah kenapa `japaneseKnives` saya taruh paling depan.

## Langkah 5 — Fitur "Add to Cart" (client component)

Pemilihan quantity + tombol butuh state → `"use client"`. File baru `src/features/add-to-cart/ui/AddToCart.tsx`:

```tsx
// src/features/add-to-cart/ui/AddToCart.tsx
"use client";

import { Minus, Plus } from "lucide-react";
import { useState } from "react";

import { type Product } from "@/entities/product";
import { Button } from "@/shared/ui/Button";
import { IconButton } from "@/shared/ui/IconButton";

interface AddToCartProps {
  product: Product;
}

export function AddToCart({ product }: AddToCartProps) {
  const [quantity, setQuantity] = useState(1);
  const [added, setAdded] = useState(false);
  const isSoldOut = product.badge === "sold-out";

  function handleAdd() {
    // Belum ada cart store. Ganti dengan dispatch ke cart context/API nanti.
    console.log("add to cart:", { slug: product.slug, quantity });
    setAdded(true);
    setTimeout(() => setAdded(false), 2000);
  }

  return (
    <div className="flex flex-col gap-4">
      <div className="flex items-center gap-4">
        <div className="flex items-center border border-border">
          <IconButton
            label="Decrease quantity"
            onClick={() => setQuantity((q) => Math.max(1, q - 1))}
          >
            <Minus size={16} />
          </IconButton>
          <span className="w-10 text-center text-sm tabular-nums">
            {quantity}
          </span>
          <IconButton
            label="Increase quantity"
            onClick={() => setQuantity((q) => q + 1)}
          >
            <Plus size={16} />
          </IconButton>
        </div>

        <Button
          size="lg"
          className="flex-1"
          disabled={isSoldOut}
          onClick={handleAdd}
        >
          {isSoldOut ? "Sold Out" : added ? "Added ✓" : "Add to Cart"}
        </Button>
      </div>

      <p className="text-xs text-muted-foreground">
        Ships in 2–4 business days · Free EU shipping over €150
      </p>
    </div>
  );
}
```

## Langkah 7 — Route halaman detail

File baru `src/app/products/[slug]/page.tsx`:

```tsx
// src/app/products/[slug]/page.tsx
import { type Metadata } from "next";
import { notFound } from "next/navigation";

import {
  allProducts,
  getProductBySlug,
  getRelatedProducts,
} from "@/entities/product";
import { ProductDetail } from "@/widgets/product-detail";

interface ProductPageProps {
  params: { slug: string };
}

// Pre-render semua slug yang diketahui saat build
export function generateStaticParams() {
  return allProducts.map((product) => ({ slug: product.slug }));
}

// SEO per produk
export function generateMetadata({ params }: ProductPageProps): Metadata {
  const product = getProductBySlug(params.slug);
  if (!product) return { title: "Product not found" };
  return {
    title: `${product.name} — Kissaki Knives`,
    description: product.description ?? product.category,
  };
}

export default function ProductPage({ params }: ProductPageProps) {
  const product = getProductBySlug(params.slug);
  if (!product) notFound();

  const related = getRelatedProducts(product);

  return <ProductDetail product={product} related={related} />;
}
```

## Alur data

```
ProductCard (href="/products/[slug]")           ← klik
        ▼
app/products/[slug]/page.tsx                     ← getProductBySlug(slug) (Server Component)
        │ product, related[]
        ▼
widgets/ProductDetail                            ← layout galeri + info + specs + reviews
        ├─ features/AddToCart  ("use client")    ← quantity + tombol
        ├─ entities/ReviewCard                   ← reuse
        └─ entities/ProductGrid                  ← reuse "You may also like"
```

Pola yang dipertahankan:
- **Hanya `AddToCart`** yang client component; sisanya Server Component → ringan.
- **`notFound()`** → otomatis render halaman 404 milik project (`app/_not-found`).
- **Data terpisah** lewat `getProductBySlug` → tinggal diganti fetch CMS/API tanpa ubah UI.
- **Reuse** `Button`, `Badge`, `RatingStars`, `ReviewCard`, `ProductGrid` yang sudah ada.

### Kalau mau URL persis seperti referensi
Referensi: `/collections/japanese-knives/products/<slug>`. Untuk itu:
1. Buat route bersarang: `src/app/collections/[handle]/products/[slug]/page.tsx` (isi sama, baca `params.slug`).
2. Ubah `href` di `ProductCard.tsx:25` jadi `/collections/${handle}/products/${product.slug}` — tapi `ProductCard` perlu tahu `handle`-nya, jadi tambah prop `collectionHandle`. Lebih ribet dan `ProductCard` dipakai di banyak tempat (carousel homepage tanpa koleksi).

**Rekomendasi:** tetap pakai `/products/[slug]` (canonical, satu sumber). Banyak toko (termasuk Shopify) menyajikan URL `/collections/.../products/...` hanya sebagai alias yang mengarah ke produk yang sama.

Mau saya lanjut ke **cart/keranjang** (context + drawer) atau **filter harga / URL state** di collection page?
