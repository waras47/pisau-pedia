## Langkah 3 — Komponen configurator (client)

Inti logikanya: satu `useState` menyimpan pilihan tiap grup, `useMemo` menghitung total harga, lalu bangun objek `Product` custom dan `addItem` ke cart.

`src/features/knife-configurator/ui/KnifeConfigurator.tsx`:

```tsx
// src/features/knife-configurator/ui/KnifeConfigurator.tsx
"use client";

import { useMemo, useState } from "react";

import {
  BASE_PRICE,
  configuratorGroups,
  CURRENCY,
} from "@/entities/configurator";
import { formatPrice, type Product } from "@/entities/product";
import { useCart } from "@/features/cart";
import { Button } from "@/shared/ui/Button";
import { Container } from "@/shared/ui/Container";
import { PlaceholderImage } from "@/shared/ui/PlaceholderImage";
import { cn } from "@/shared/lib/utils";

// State = { groupId: optionId }. Default: opsi pertama tiap grup.
type Selection = Record<string, string>;

const defaultSelection: Selection = Object.fromEntries(
  configuratorGroups.map((g) => [g.id, g.options[0].id]),
);

export function KnifeConfigurator() {
  const { addItem } = useCart();
  const [selection, setSelection] = useState<Selection>(defaultSelection);

  // Hitung harga total dari semua priceDelta yang dipilih
  const total = useMemo(() => {
    return configuratorGroups.reduce((sum, group) => {
      const option = group.options.find(
        (o) => o.id === selection[group.id],
      );
      return sum + (option?.priceDelta ?? 0);
    }, BASE_PRICE);
  }, [selection]);

  // Ringkasan label pilihan (untuk nama produk & deskripsi)
  const summary = useMemo(() => {
    return configuratorGroups.map((group) => ({
      group: group.label,
      option:
        group.options.find((o) => o.id === selection[group.id])?.label ?? "",
    }));
  }, [selection]);

  function select(groupId: string, optionId: string) {
    setSelection((prev) => ({ ...prev, [groupId]: optionId }));
  }

  function handleAddToCart() {
    // Slug unik berdasar kombinasi, supaya item custom yg sama digabung
    const slug = `custom-${Object.values(selection).join("-")}`;
    const bladeLabel = summary.find((s) => s.group === "Blade profile")?.option;

    const customProduct: Product = {
      id: slug,
      slug,
      name: `Custom ${bladeLabel ?? "Knife"}`,
      category: "Custom Build",
      price: total,
      currency: CURRENCY,
      rating: 0,
      reviewCount: 0,
    };

    addItem(customProduct, 1);
  }

  return (
    <section className="py-16">
      <Container className="grid gap-12 lg:grid-cols-2">
        {/* Preview */}
        <div className="lg:sticky lg:top-8 lg:h-fit">
          <PlaceholderImage ratio="square" label="Your custom knife" />
          <div className="mt-6 border border-border bg-surface p-6">
            <h3 className="font-display text-lg font-semibold tracking-tightest">
              Your configuration
            </h3>
            <dl className="mt-4 divide-y divide-border border-y border-border">
              {summary.map((row) => (
                <div
                  key={row.group}
                  className="flex justify-between gap-4 py-2.5 text-sm"
                >
                  <dt className="text-muted-foreground">{row.group}</dt>
                  <dd className="text-foreground">{row.option}</dd>
                </div>
              ))}
            </dl>
          </div>
        </div>

        {/* Pilihan */}
        <div className="flex flex-col gap-10">
          <div>
            <span className="font-accent text-lg italic text-copper">
              Endless possibilities
            </span>
            <h1 className="font-display text-3xl font-semibold tracking-tightest sm:text-4xl">
              Build your knife
            </h1>
          </div>

          {configuratorGroups.map((group) => (
            <fieldset key={group.id} className="flex flex-col gap-3">
              <legend className="mb-2 text-sm font-medium uppercase tracking-widest2 text-muted-foreground">
                {group.label}
              </legend>
              <div className="flex flex-wrap gap-2">
                {group.options.map((option) => {
                  const active = selection[group.id] === option.id;
                  return (
                    <button
                      key={option.id}
                      type="button"
                      onClick={() => select(group.id, option.id)}
                      aria-pressed={active}
                      className={cn(
                        "border px-4 py-2.5 text-sm transition-colors",
                        active
                          ? "border-accent bg-accent text-accent-foreground"
                          : "border-border text-foreground hover:border-foreground/60",
                      )}
                    >
                      {option.label}
                      {option.priceDelta !== 0 ? (
                        <span
                          className={cn(
                            "ml-2 text-xs",
                            active
                              ? "opacity-80"
                              : "text-muted-foreground",
                          )}
                        >
                          {option.priceDelta > 0 ? "+" : "−"}
                          {formatPrice(
                            Math.abs(option.priceDelta),
                            CURRENCY,
                          )}
                        </span>
                      ) : null}
                    </button>
                  );
                })}
              </div>
            </fieldset>
          ))}

          {/* Total + CTA */}
          <div className="flex items-center justify-between border-t border-border pt-6">
            <div>
              <span className="text-xs uppercase tracking-widest2 text-muted-foreground">
                Total
              </span>
              <p className="text-2xl font-semibold">
                {formatPrice(total, CURRENCY)}
              </p>
            </div>
            <Button size="lg" onClick={handleAddToCart}>
              Add to Cart
            </Button>
          </div>
        </div>
      </Container>
    </section>
  );
}
```

## Cara kerjanya

```
entities/configurator        ← DATA: grup opsi + priceDelta + BASE_PRICE
        ▼
features/knife-configurator  ← "use client"
   ├─ useState(selection)     pilihan tiap grup
   ├─ useMemo(total)          BASE_PRICE + Σ priceDelta terpilih
   ├─ useMemo(summary)        label utk nama & ringkasan
   └─ addItem(customProduct)  → cart (dari fitur sebelumnya)
        ▼
app/pages/configurator       ← route, render komponennya
```

Poin penting:
- **Harga = `BASE_PRICE + Σ priceDelta`**, dihitung di `useMemo` → otomatis re-render saat pilihan berubah. Ini inti dari "configurable".
- **Produk custom dibuat on-the-fly** sebagai objek `Product`, lalu masuk ke cart yang sama. Slug-nya unik per kombinasi → konfigurasi identik digabung quantity-nya.
- **Reuse total**: `Button`, `Container`, `PlaceholderImage`, `formatPrice`, dan `useCart` — tak ada komponen baru di `shared`.
- **Data terpisah dari UI** → tambah/ubah opsi cukup edit `configurator.data.ts`, komponen tak perlu disentuh.

### Catatan untuk produksi
- Slug custom (mis. `custom-gyuto-210-aogami-...`) **tidak punya halaman `/products/[slug]`** — jadi link dari cart ke produk custom akan 404. Untuk demo tak masalah; untuk live, di cart bisa nonaktifkan link saat `category === "Custom Build"`, atau simpan detail konfigurasi di order.
- Saat checkout Xendit, route `/api/checkout` menghitung harga via `getProductBySlug` — produk custom **tidak ada di katalog**, jadi akan di-skip. Untuk mendukung custom build, tambahkan cabang: jika slug diawali `custom-`, percayai harga dari payload **atau** (lebih aman) kirim `selection` dan hitung ulang dari `configuratorGroups` di server. Bisa saya buatkan kalau mau.

Mau saya lanjutkan menyambungkan **custom build ke checkout Xendit** (hitung ulang harga konfigurasi di server), atau cukup sampai di sini?
